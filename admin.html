The dashboard lives on the worker, behind GitHub sign-in.

Open the dashboard

Not wired up yet. The dashboard is a Cloudflare Worker: it holds the OAuth secret, checks that the GitHub account signing in is the right one, and serves the numbers. None of that can be done by a page on GitHub Pages, which is why it is not here.

One command does all of it:

cd worker && ./setup.sh

It creates the database, deploys, generates and stores the secrets, and points this page and the site at the result. It stops twice for the two steps that need a browser — signing in to Cloudflare, and creating the GitHub OAuth app — and tells you exactly what to paste. Safe to re-run. The long version is in worker/README.md.

Until it has run, the collector sends nothing at all, so the site behaves exactly as it does now.
